# Asteroids Automated Play in MAME

This project contains Lua and Python scripts that enable automated play of Atari's *Asteroids* (1979) inside MAME.

A Lua script running in MAME sends game data to a local Python server. The server decodes the game's object table and decides which controls to press. Avoiding player ship collision is prioritized. Otherwise, the heuristics aim the player ship at the highest-priority target and fire. The Python server sends MAME keypresses back to the MAME Lua script to control gameplay. Information overlays showing what the AI sees can be toggled.

## Tested with

- **MAME 0.270**
- **Asteroids (rev 4)**, MAME set `asteroid`
- **macOS 26.5.2** (Intel x86_64), **zsh 5.9** shell

It seems likely to work with other MAME versions, Asteroids ROM revisions, operating systems, and/or
shells. Let me know how it goes. I struggled to find working examples of MAME Lua<>Python socket communication.  The approach here works well and you are welcome to extend it as you like.  I used Claude Code to help me clear the way.

## Files

| File            | Purpose                                                                                                |
|-----------------|--------------------------------------------------------------------------------------------------------|
| `ast_link.lua`  | MAME autoboot Lua script                                                                               |
| `ast_server.py` | Python server. Handles local socket communication, decodes and tracks objects, and calls the autopilot |
| `ast_ai.py`     | The autopilot: threat check, evasion, target choice and aiming                                         |
| `cfg/`          | MAME configuration for `asteroid`                                                                      |

## Requirements

- Python 3 with `numpy` (`pip3 install numpy`)
- A MAME build (tested with version 0.270)
- Asteroids (rev 4) ROM set, `asteroid.zip`, in `roms/`. You will have to find your own ROM set.
  **The ROMs are not included here.**

## Run

In a terminal window, start the Python server first:

```zsh
python3 ast_server.py
```

In the arcade, each game of Asteroids would start from a random point.  Since we are emulating Asteroids and running a bot, we see the same game played each time.  To add variety, a pseudo-randomized starting point is generated by default. When a game starts the server seeds Asteroids' own 16-bit random-number generator (65,535 possible starting points). The session seed is logged as `game N start: RNG 0x....`. From the command line, you can start future games using a selected seed number if you want to see a replay.

| Option | Effect |
|--------|--------|
| `--random on` | Default. Seed from the system clocks, process id and OS entropy |
| `--random off` | Leave the game's generator alone (every run plays the same) |
| `--random <N>` | Use seed N, e.g. one printed earlier, to replay that session exactly |

In a second terminal, start MAME using:

```zsh
mame asteroid -rompath ../roms -window -autoboot_script ../ast_link.lua
```

Make sure to edit `-rompath ../roms` to match your configuration.

The Python autopilot script inserts a coin, starts the game, and restarts it after a game
ends. If the Python server doesn't reply within 2 seconds, MAME stops waiting for it.

## Keys (in MAME)

| Key | Action |
|-----|--------|
| `I` | Interrupt autopilot on/off (off = you play) |
| `B` | Boxes around objects and aim line on/off |
| `O` | Object list on/off |
| `V` | View projected object positions on/off |
| `]` / `[` | Project further / less far ahead (5–300 frames, step 5) |
| `A` | AI state text on/off |
| `S` | Score overlay on/off.  Displays actual score beyond 99,999 rollover. |
| `.` / `,` | Faster / slower emulation (0.25x–8x, default 1x) |
| `=` / `-` | MAME volume up / down (2 dB steps) |

The score overlay (top right) shows the actual total score, which keeps counting past the
arcade's 99,990 rollover (up to 9,999,999,999), the ships remaining and the level (wave) number.
Speed and volume changes are shown on screen for 3 seconds.
